# 🏴‍☠️ 廚房冒險王：食材群島大航海

給 9 歲左右孩子的闖關遊戲，幫助他一步步學會「做早餐 → 規劃採買 → 假日料理 → 一日三餐」。

## 玩法
- **航海圖**：四座島嶼對應四個學習階段，完成任務會解鎖下一座島。
- **任務**：每個任務都有步驟與安全等級（🟢🟡🟠）。孩子按「我完成了」，家長在「家長區」蓋章後才得到經驗值、金幣與食靈。
- **餐盤挑戰**：用「我的餐盤」六大類設計均衡早餐。
- **食靈圖鑑**：收集原創的食材夥伴。
- **食譜本**：完成的料理自動收錄，可寫下心得。
- **安全守則**：廚房安全等級與小測驗。

純靜態網站（HTML/CSS/JS），進度存在瀏覽器 localStorage，可在家長區匯出／匯入。
